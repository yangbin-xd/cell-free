## Project Overview

GNN-based digital twin for cell-free massive MIMO wireless networks. Given a network topology (AP/UE locations, association matrix A, power allocation P), three GNN models predict signal power, interference power, and spectral efficiency (bits/s/Hz) per UE.

The dataset comes from DeepMIMO (ray-tracing simulation): 12 APs, 2500 UE locations, CSI shape `(12, 2500, 1, 32, 12)`.

## Running the Pipeline

Scripts must be run from the repo root (`/home/binyang/torch_ws/src/GNN`) since all paths are relative.

**Step 1: Generate training/test data**
```bash
python generate.py
# Outputs to data/train/ and data/test/ (8000 train, 2000 test samples)
```

**Step 2: Train GNN models (run in order)**
```bash
python signal_map.py    # trains SignalModel -> model/signal_map.pth
python interf_map.py    # trains InterfModel -> model/interf_map.pth
python rate_map.py      # fine-tunes RateModel on top of signal+interf -> model/rate_map_15dB.pth
```

**Step 3: Run digital twin inference**
```bash
python demo.py          # single test case prediction and error plots
```

**Step 4: Baseline comparisons and result plots**
```bash
python radio_map.py     # builds grid radio map (used by baseline 2)
python Kriging.py       # builds Kriging map (used by baseline 3)
python query.py         # runs baseline 2 (radio map query)
python beam.py          # runs baseline 3 (Kriging-based)
python sinr_map.py      # runs baseline 1 (SINR map)
python twin.py          # final comparison plots -> result/*.pdf
```

**Utility scripts**
```bash
python main.py          # explore AP selection and power allocation strategies
python scenario.py      # plot network layout
python analyze.py       # analyze signal/interference/rate distributions
python plot_loss.py     # plot training loss curves
```

**Ablation studies** (in `ablation/`)
```bash

python ablation/signal_dist_map.py    # distance-only edges
```

## Architecture

### Data flow

```
data/BS_loc.npy, UE_loc.npy, CSI.npy   (raw DeepMIMO)
        |
    main.py: CellFree class
        |  random_choose(K) -> selects K UEs
        |  improved_random_selection(p) -> AP-UE association matrix A (L x K)
        |  random_power(A) -> power matrix P (L x K)
        |  calculate_sinr(A, P) -> signal (dBW), interf (dBW), rate (bits/s/Hz)
        |
    generate.py: generate_data() -> saves to data/train/ and data/test/
        |  Each sample: variable ap_num (active APs), ue_num (10-30 UEs)
        |  Stored padded to max_ap_num=12, max_ue_num=30
        |
    process.py: loads .npy -> tensors, computes z-score normalization stats
        |  loc_mean/loc_std (from generate.py), signal_mean/std, interf_mean/std, rate_mean/std
        |  RadioMapDataset + split_train_val() -> DataLoader (batch_size=128)
```

### GNN Models

All models use `torch_geometric.nn.TransformerConv` with hidden=128, head=4, layers=1.

- **SignalModel** (`signal_map.py`): AP -> UE message passing only. Edge attr: `[power, dist², dir_x, dir_y]` for served edges (A[l,k]=1).

- **InterfModel** (`interf_map.py`): Bidirectional. Pass 1: UE->AP (served edges). Pass 2: AP->UE (top-8 nearest APs, excluding fully-served edges). Edge attr for interference: `[1-power, dist², dir_x, dir_y]`.

- **RateModel** (`rate_map.py`): Wraps SignalModel + InterfModel (partially frozen), computes SINR analytically: `SINR = signal_linear / (interf_linear + noise)`, then `rate = log2(1 + SINR)`. One model per SNR value; saved as `model/rate_map_{snr}dB.pth`.

### Key Implementation Details

- **Variable graph sizes**: Each sample has a different number of active nodes/edges. Training iterates per-sample inside each batch (no PyG batching/padding).
- **Normalization**: Location inputs normalized with `(x - loc_mean) / loc_std`. Targets z-score normalized. Denormalization applied at inference.
- **DeepMIMO axis swap**: x and y axes are swapped on load: `BS_loc = BS_loc[:, [1,0,2]]`.
- **Training**: AdamW, ReduceLROnPlateau (patience=10, factor=0.1), early stopping (patience=20). Signal/interf use L1Loss; interference also has MSELoss variant.
- **SNR range**: 0 to 30 dB in steps of 5 (7 values, index `int(snr/5)`). Noise = `-87 - snr` dBW.
